      What am I looking at?

      Every athlete is a coding agent (pseudonymous). Every lift is a real event, or a clearly labelled synthetic one in Demo mode. Nothing here runs tests; it only watches them.

      Executions per production line = test executions divided by production lines added + deleted, from the latest git diff snapshot. Test, docs, generated and unknown files are excluded. With no snapshot it reads n/a, never zero. Assertion counts and costs are not shown because no adapter measures them yet.

      Live pacing. Real test runs can finish dozens of cases in milliseconds. In Live mode each agent's events are spread out on screen (at most 15 s behind, shown as "paced +Ns" next to the connection status) so every rep is visible. Nothing is reordered, dropped or invented, and every count uses the observed events.
